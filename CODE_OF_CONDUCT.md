# Code of conduct

Jev Social is committed to a welcoming, harassment-free community for everyone.

## Expected behavior

- Be respectful, specific, and constructive.
- Assume good intent while focusing discussion on observable behavior and evidence.
- Respect privacy. Never publish credentials, browser data, captured personal information, or private social content.
- Accept maintainers' decisions about scope, safety, and platform compliance.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, doxxing, deliberate exposure of private data, spam, and abusive or disruptive conduct are not permitted in project spaces.

## Enforcement

Maintainers may edit or remove content and temporarily or permanently restrict participation when behavior violates this policy. Report conduct concerns privately through the [socai Discord](https://discord.gg/CpQdA7bwt8) to a server moderator. Security vulnerabilities belong in [private security advisories](https://github.com/socai-io/jev-social/security/advisories/new).

This policy applies to repository discussions, issues, pull requests, reviews, and project community spaces.
