THE LOOP

Jev decides. socai acts.

The model never writes shell commands or arbitrary selectors.

  1. 01

    Route the goal

    Jev selects Instagram, TikTok, or LinkedIn from a typed choice.

  2. 02

    Choose one operation

    Search, open an observed post or profile, read comments, download selected video, or finish.

  3. 03

    Run the real CLI

    socai drives your existing Chrome session and returns structured evidence.

  4. 04

    Stream the result

    Post cards stay visible while Jev evaluates the new state and builds the final report.

WHY JEV FITS

A changing decision space, not a blank check.

Every step offers only operations supported by the installed socai CLI and only targets observed in captured results. Attempted actions disappear from the next choice set.

  • Low-confidence and malformed decisions do not execute.
  • Login gates and step limits preserve honest partial results.
  • Sources, comments, media, and timing remain inspectable.
RUN LOCALLY

Your browser. Your session. Your evidence.

Requires Node 20+ and an OpenRouter key with Jev access. Onboarding offers to install the current socai CLI when it is missing.
