01 · START KEV

One local decision endpoint.

Kev exposes the TypeSafe-compatible /v1/systemone route Jev Social expects. Start it first and leave it running.

  • Kev's model and inference requirements still apply.
  • The first model load may take longer than later choices.
  • Jev Social accepts only an exact loopback HTTP endpoint.
TERMINAL 1
git clone https://github.com/jaredpalmer/kev.git
cd kev
git checkout 2855ba2a55a80579176a459f78b95d03548cabb5
uv sync --extra serve
uv run --extra serve python -m kev.serve --run jaredpalmer/kev-4b@139fdd94f1b6a6ad80cc15e08fcb99cac885a101 --port 8009
02 · START SIMPLE JEV

A second tested endpoint.

Simple Jev serves a Choice-capable open model through the same route. The setup below pins the source and model revision used by the compatibility guide.

  • Python 3.12+, a hardware-appropriate PyTorch build, and enough model memory are required.
  • The first run downloads the pinned Qwen weights unless they are already cached.
  • The seven-case check covers decision compatibility, not browser speed or broad model quality.
TERMINAL 1 · SIMPLE JEV
git clone https://github.com/featherless-ai/simple-jev.git
cd simple-jev
git checkout c077d5dfdb5c2c7dd24b17d5f556f07e0162dc1c
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e './hf-server'
python hf-server/hf_server.py --model Qwen/Qwen3.5-4B --revision 851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a --served-model-name simple-jev-qwen3.5-4b --enforce-model-id --device auto --dtype bfloat16 --max-model-len 16384 --max-choice-options 255 --max-batch-size 4 --max-batch-tokens 16384 --host 127.0.0.1 --port 8000
curl --fail http://127.0.0.1:8000/health
03 · RUN JEV SOCIAL

Route locally. Research in Chrome.

Use the pair that matches the server you started. Both keep report generation deterministic; the social sites still load through your browser and normal network connection.

TERMINAL 2 · KEV
export JEV_SOCIAL_SYSTEM_ONE_URL=http://127.0.0.1:8009/v1/systemone
export JEV_SOCIAL_SYSTEM_ONE_MODEL=kev-latest
export JEV_SOCIAL_SYSTEM_ONE_TIMEOUT_MS=120000
export OPENROUTER_REPORT_MODEL=off
npx github:socai-io/jev-social#v0.1.8
TERMINAL 2 · SIMPLE JEV
export JEV_SOCIAL_SYSTEM_ONE_URL=http://127.0.0.1:8000/v1/systemone
export JEV_SOCIAL_SYSTEM_ONE_MODEL=simple-jev-qwen3.5-4b
export JEV_SOCIAL_SYSTEM_ONE_TIMEOUT_MS=120000
export OPENROUTER_REPORT_MODEL=off
npx github:socai-io/jev-social#v0.1.8

THE BOUNDARY

Local does not mean imaginary.

The decision model moves onto your machine. The evidence still comes from the live sites you asked socai to inspect.

  1. 01

    Local model decides

    The local model selects from the operations Jev Social currently offers.

  2. 02

    Code checks

    Unsupported, stale, malformed, and low-confidence choices do not execute.

  3. 03

    socai reads

    The installed CLI uses your Chrome session to collect posts, comments, and requested media.

  4. 04

    Sources stay

    Captured cards remain visible and the deterministic report links back to the evidence.

HONEST LIMITS

No hosted key.
Not fully offline.

Local decisions remove the OpenRouter dependency. They do not remove Chrome, socai, the social sites, or their access rules.

NETWORK

Live sites stay live

Instagram, TikTok, and LinkedIn still require normal network access and an usable browser session.

ACCESS

No gate bypass

Login prompts, challenges, rate limits, and unavailable pages remain visible stop conditions.

SAFETY

Fail closed

Jev Social refuses remote System One URLs, redirects, oversized responses, and invalid choices.
