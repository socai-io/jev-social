WHAT DOES IT DO, AND WHERE DOES JEV FIT?

A decision loop around real evidence.

Jev is the judgment layer. Application code owns the allowed operations, and socai owns browser execution.

  1. 01

    State the goal

    Ask a concrete research question and, when useful, give a target count or stopping condition.

  2. 02

    Jev chooses

    Jev selects the platform, then one supported operation and one already observed target.

  3. 03

    Chrome observes

    The local socai CLI searches, opens, scrolls, and extracts through your existing browser session.

  4. 04

    Evidence returns

    Cards stream into the UI, the action set changes, and the final report cites captured source URLs.

QUESTIONS THAT FIT

Ask for a finding you can check.

Good goals name the platform or let Jev route one clear platform, request a small evidence set, and say what should be compared.

  • Use a concrete topic instead of a generic “research everything” request.
  • Ask Jev to open relevant details and comments, not just collect search cards.
  • Keep the first run small; four useful records are enough to inspect the workflow.
THE BOUNDARY

Useful because the action space stays small.

The browser result is untrusted evidence. It can change what Jev sees next, but it cannot become an instruction.

  1. 01

    No invented tools

    Malformed, unknown, and low-confidence decisions stop before a CLI command runs.

  2. 02

    No arbitrary targets

    Action targets come from captured results or an explicit HTTPS social URL in the goal.

  3. 03

    No account changes

    The application does not post, like, follow, message, purchase, or change settings.

  4. 04

    No fake success

    Login gates, access limits, empty results, and interruptions return partial evidence.

QUICK ANSWERS

Know what stays in code.

What does Jev do?
It selects the platform and next operation from typed choices. It does not generate commands, selectors, or URLs.
Can Jev Social post?
No. The application exposes read-only research operations and does not change social accounts.
Does it require OpenRouter?
OpenRouter Jev is the default. Pinned Kev and Simple Jev setups can provide decisions on an exact loopback endpoint.
What still needs network access?
Chrome and the selected social platform still require normal network access. Only typed decision calls can move to an explicit loopback provider.
